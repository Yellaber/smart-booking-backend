# SmartBooking API

1. Clonar proyecto.

2. Instalar dependencias:
```
npm install
```

3. Clonar el archivo ```.env.template``` y renombrarlo a ```.env```.

4. Cambiar las variables de entorno ```DB_PASSWORD``` y ```DB_NAME```.

5. Levantar la Base de Datos:
```
docker-compose up -d
```

6. Ejecutar en modo desarrollo:
```
npm run start:dev
```
